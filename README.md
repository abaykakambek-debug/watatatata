# Deal Radar — парсер книг на Python

Учебный проект спринта **Data Hunter**, урок 5: «Интернет-разведка. HTTP и парсинг сайтов».

**Цель:** научиться отправлять HTTP-запросы, исследовать HTML с помощью DevTools, находить элементы по CSS-селекторам, извлекать структурированные данные и сохранять код в Git.

## 1. Что делает проект

Скрипт открывает учебный сайт [Books to Scrape](https://books.toscrape.com/), получает HTML главной страницы и извлекает **до 20 книг**. Для каждой книги он определяет:

- **Название** — атрибут `title` у ссылки внутри `h3`;
- **Цену** — текст элемента `.price_color` (в фунтах стерлингов);
- **Рейтинг** — число от 1 до 5, закодированное классом `One`, `Two`, `Three`, `Four` или `Five`;
- **Ссылку** — абсолютный URL карточки товара.

Результат выводится в консоль в виде таблицы. В текущей версии проект не сравнивает магазины, не сохраняет данные в базу и не обходит страницы каталога.

## 5. Как работает программа

**Этап 1 — запрос:** `fetch_html()` выполняет `requests.get(BASE_URL, timeout=10)`. Метод `raise_for_status()` вызывает исключение при HTTP-ошибках 4xx/5xx. HTML возвращается как строка.

**Этап 2 — HTML:** `BeautifulSoup(html, "html.parser")` преобразует HTML в дерево элементов.

**Этап 3 — карточки:** `soup.select("article.product_pod")` находит все карточки книг. Срез `[:20]` ограничивает выборку двадцатью элементами.

**Этап 4 — поля:** `select_one("h3 a")` находит ссылку с названием, `.price_color` — цену, `p.star-rating` — рейтинг. `get("title")` читает HTML-атрибут, `get_text(strip=True)` — текст элемента. Рейтинг определяется по CSS-классу.

**Этап 5 — структура данных:** каждая книга превращается в Python-словарь с ключами `title`, `price`, `rating`, `url`; словари собираются в список.

**Этап 6 — вывод:** `print_books()` печатает выровненную таблицу. Если карточка не содержит необходимых элементов, она пропускается.

### Используемые CSS-селекторы

| Селектор | Что ищет |
|---|---|
| `article.product_pod` | Карточку книги |
| `h3 a` | Ссылку внутри заголовка карточки |
| `.price_color` | Элемент цены |
| `p.star-rating` | Элемент с классами рейтинга |

**Важно:** CSS-селекторы зависят от HTML сайта. Если разметка изменится, парсер может потребовать обновления.

## 7. Как найти селекторы самостоятельно

1. Откройте https://books.toscrape.com/ в браузере.
2. Нажмите **F12** (или правой кнопкой мыши → **Inspect / Просмотреть код**).
3. Выберите инструмент выбора элемента и нажмите на название книги.
4. Посмотрите HTML-тег, атрибут `title` и родительский блок `article.product_pod`.
5. Аналогично найдите цену и рейтинг.
6. Сверьте селекторы с таблицей выше.
7. Измените селектор в `main.py` и проверьте результат.

## 10. Ошибки и способы исправления

| Проблема | Возможная причина | Что сделать |
|---|---|---|
| `ModuleNotFoundError` | Библиотеки не установлены в активное окружение | `python -m pip install -r requirements.txt` |
| `ConnectionError` | Нет сети или сайт недоступен | Проверьте интернет и адрес |
| `Timeout` | Сервер не ответил вовремя | Попробуйте позже; не отправляйте запросы непрерывно |
| `403 Forbidden` | Сервер запретил запрос | Не обходите ограничения; изучите правила сайта |
| `404 Not Found` | Неверный URL | Проверьте адрес |
| Найдено 0 книг | Изменились HTML или селекторы | Проверьте страницу через DevTools |
| Неверный рейтинг | Классы HTML отличаются | Посмотрите `class` у `p.star-rating` |
| Странные символы в цене | Проблема с кодировкой терминала | Убедитесь, что терминал поддерживает UTF-8 |

## 11. Этика парсинга

- Используйте сайт **Books to Scrape**, созданный для обучения.
- Перед парсингом других сайтов проверяйте `robots.txt`, условия использования и применимые законы.
- Не обходите авторизацию, капчи и ограничения доступа.
- Не собирайте персональные данные без законных оснований.
- Для многостраничных парсеров добавляйте паузы между запросами и соблюдайте ограничения частоты.
- В этом проекте выполняется один GET-запрос на главную страницу.
